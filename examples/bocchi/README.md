# 波奇酱

粉色双层边框、奶油色的底，窗口外绕着一圈音频线。横排时波奇酱抱着吉他趴在窗口上沿，左上角一台小音箱，上面趴着只黑猫；竖排时她躲在窗口左边偷看。只有浅色一种外观。

青简已经自带这个主题，在「设置 → 候选窗口 → 主题」里选「波奇酱」即可，不用下载。这里放的是它的源文件，写自己的主题时可以照着改。

## 设计

- 高亮是粉色圆角块，候选深色、译文偏灰的玫瑰色。
- 竖排每个候选的译文在词下面另起一行。
- 拨片、星星、音符散在窗口边上，音符会轻轻晃。
- 横排右边两个粉色按钮是翻页的样子，点不了，用翻页键翻。
- Windows 的悬浮状态条：左边缩在纸箱里睡觉的波奇酱，「中」是粉色方块，后面是标点、键盘、设置。

## 素材

- 人物、小音箱（`images/*.png`）：AI 生成，从概念稿里提取、补全，青简裁剪缩放后使用；竖排的人物是水平翻转过的。
- 音频线、拨片、星星、音符、各个图标（`images/*.svg`）：照着概念稿重画的矢量图。
