# 大肥鱼

蓝边玻璃底，三道内框，底下一层水波。横排时鲸鱼女仆趴在窗口上沿，旁边冒个气泡说「假如给我三天多模态！」；竖排时她扒在窗口右边探头。底色和人物都是浅色画的，所以只有浅色一种外观。

青简已经自带这个主题，在「设置 → 候选窗口 → 主题」里选「大肥鱼」即可，不用下载。这里放的是它的源文件，写自己的主题时可以照着改。

## 设计

- 高亮是浅蓝渐变的圆角块，序号、候选、译文都用深海蓝，译文淡一档。
- 竖排每个候选的译文在词下面另起一行，没有译文的候选只占一行。
- 横排右边两个圆按钮是翻页的样子，点不了，用翻页键翻。
- Windows 的悬浮状态条：左边抱着鲸鱼睡觉的人物，右边一排白色小按钮（中英、月亮、标点、键盘、设置）。

## 素材

- 人物（`images/girl-*.png`）：AI 生成，从概念稿里提取、补全，青简裁剪缩放后使用。
- 鲸鱼、气泡、水波、爱心、对白框、各个图标（`images/*.svg`）：照着概念稿重画的矢量图。
