# 初音未来

青色切角的科技感边框，左边一道青色括线，右上一抹粉色角标，右下一排小音柱。横排时初音未来趴在窗口上沿笑，竖排时她从窗口右边探头，高亮的那一行带个小音符，底下一个粉色的「01」。只有浅色一种外观。

青简已经自带这个主题，在「设置 → 候选窗口 → 主题」里选「初音未来」即可，不用下载。这里放的是它的源文件，写自己的主题时可以照着改。

## 设计

- 边框是九宫格 SVG，窗口多宽多高四个角都不变形。
- 高亮是青色圆角块，序号跟着变深。
- 竖排每个候选的译文在词下面另起一行。
- Windows 的悬浮状态条：左边趴着睡觉的初音，「中」是青色方块，后面是月亮、标点、键盘、设置。

## 素材

- 人物（`images/miku-*.png`）：AI 生成，从概念稿里提取、补全，青简裁剪缩放后使用。
- 边框、角标、音柱、音符、各个图标（`images/*.svg`）：照着概念稿重画的矢量图。
- 随主题以 GPL-3.0-or-later 发布。
