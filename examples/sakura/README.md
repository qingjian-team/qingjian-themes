# 樱花

青简内置的展示主题：粉紫玻璃底，左上角趴着一个女孩，四周点缀樱花、蝴蝶结、皇冠与吊牌。底色与装饰都是浅色画的，所以只有浅色一种外观。

青简已经自带这个主题，在「设置 → 候选窗口 → 主题」里选「樱花」即可，不用下载。这里放的是它的源文件，写自己的主题时可以照着改。

## 设计

- 窗口左边留出 60 的内边距，给人物的身体与吊牌；改人物位置或大小时一起改。
- 高亮候选是粉色渐变的圆角块，序号、候选、译文各用一种颜色区分。
- 底部一条状态栏写着两句英文标语，可以换成自己的话。

## 素材

- 人物、樱花、吊牌、猫（`images/*.png`）：AI 生成，青简调整后使用。
- 蝴蝶结、皇冠、爱心、月亮、花瓣、星光、翻页箭头（`images/*.svg`）：照着上面的插画手绘临摹。
