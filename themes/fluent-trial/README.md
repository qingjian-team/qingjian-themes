# 轻简横排

浅色、紧凑的横排候选窗口：中文候选依次排列，译词显示在各候选下方，序号与翻页箭头保持低调。长译词可能撑宽候选栏，建议在「设置 → 候选」适当减少每页候选数。

## 使用

在「设置 → 外观」选择「轻简横排」，将排布设为横排；需要只在输入框显示拼音时，将拼音显示位置设为「只在行内」。译词语言在「设置 → 候选」选择。

本主题只修改候选窗口外观，不提供翻译服务。整句译文由青简自身功能与用户选择的服务决定。Windows 上用青简 0.3.2 测试；macOS 尚未实机验证。
